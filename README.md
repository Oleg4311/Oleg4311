## Projects (English)

Production-minded side projects in TypeScript, Go, Rust and Python — each with tests, CI, a release with checksums and build provenance, and a live demo where there is a browser part. Highlights: a linter for agent instruction files (AGENTS.md, CLAUDE.md) that checks them against the real repository, a regex engine written from scratch in Rust (Pike VM, differentially tested against the `regex` crate), a PostgreSQL migration rehearsal tool that measures real locks and queueing, a browser tool that compares two EXPLAIN plans (parsers verified against live PostgreSQL 14–18), JavaScript vs WebAssembly (scalar and SIMD) image filters with bit-identical output and an in-browser benchmark, a pandas library for Russian tabular data (encoding detection, 1C bank files, validators cross-checked against the TypeScript implementation), a double-entry ledger whose invariants live in the database, a PostgreSQL job queue in Go (`SKIP LOCKED`, leases), a Redis-compatible server verified with the real `redis-cli`, and a zero-dependency Russian-locale toolkit published on npm as `@oleg4311/ru-kit`.
